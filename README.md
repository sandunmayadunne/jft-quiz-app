# 🌸 JFT Basic Practice App

> **Practice - අපි ඉගෙන ගත් දේවල් පුහුණු වෙමු 🌸**

A beautiful, mobile-friendly quiz application designed for Sri Lankan students preparing for the **JFT Basic Exam**. This app helps users practice Japanese greetings (Aisatsu) and the Hiragana alphabet interactively.

## 🎯 Features

*   **Aisatsu Quiz (ආචාර සමාචාර):** Practice 32+ essential Japanese greetings with multiple-choice questions (Sinhala meaning to Romaji).
*   **Hiragana Quiz (හිරගනා හෝඩිය):** Master the Hiragana alphabet, including basic characters, Dakuten (Tenten ゛), and Handakuten (Maru ゜).
*   **Mobile-First Design:** Fully responsive layout with a Japanese traditional Sakura (Cherry Blossom) color theme.
*   **Real-time Tracking:** Live question counter (e.g., ප්‍රශ්නය: 1 / 32) instead of just showing the score.
*   **Custom Alert Modal:** A beautifully designed custom confirmation popup when trying to exit a quiz midway.
*   **Randomized Questions & Options:** Questions and multiple-choice options are shuffled every time you start a new quiz.

## 🛠️ Built With

This project is built completely with vanilla web technologies. No external libraries or frameworks were used.

*   **HTML5** - Structuring the web application.
*   **CSS3** - Styling, animations, and mobile responsiveness.
*   **JavaScript (ES6)** - Core logic, quiz generation, and DOM manipulation.
*   **Vercel** - Fast and reliable cloud deployment.
